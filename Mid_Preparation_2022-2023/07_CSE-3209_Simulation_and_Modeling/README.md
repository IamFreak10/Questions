## 📑 Core Syllabus Areas for Mid-Term
1. **Simulation Concepts & Process**:
   - Definition of Simulation, when simulation is appropriate vs. not appropriate.
   - Systems and system environment: Components (Entities, Attributes, Activities, Events, State variables).
   - Discrete systems vs. Continuous systems.
   - Steps in a simulation study (Model building, data collection, verification, validation, experimental design).
2. **Discrete-Event Simulation (DES)**:
   - Concepts: Event, Event notice, Event list, Clock, System state, Statistical counters.
   - Simulation Clock & Time-Advance Mechanisms: Next-Event Time-Advance vs. Fixed-Increment Time-Advance.
   - Manual simulation table generation: Single-server queue (customer arrivals, service times, queue lengths, idle times).
3. **Statistical Models in Simulation**:
   - Discrete distributions: Bernoulli, Binomial, Poisson distribution.
   - Continuous distributions: Uniform, Exponential, Gamma, Weibull, and Normal distribution.
   - Poisson process & inter-arrival time characteristics.
