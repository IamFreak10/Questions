## 📑 Core Syllabus Areas for Mid-Term
1. **Microprocessor Fundamentals & Architecture**:
   - 8085 / 8086 Microprocessor internal architecture: Bus Interface Unit (BIU) and Execution Unit (EU).
   - Register organization: General-purpose (AX, BX, CX, DX), Pointer & Index (SP, BP, SI, DI), Segment registers (CS, DS, SS, ES), Instruction Pointer (IP), and Flags register.
   - Memory segmentation & Physical address calculation: $\text{Physical Address} = (\text{Segment} \times 16) + \text{Offset}$.
2. **CPU & System Architecture Comparisons**:
   - Microprocessor vs. Microcontroller.
   - RISC vs. CISC architectures (Instruction set simplicity, pipelining, register counts).
   - GPU vs. CPU architecture (Parallel stream processing vs. latency-oriented sequential computing).
   - Clock cycles, bus cycles, and CPU performance metrics.
3. **Peripheral Devices & Interfacing**:
   - Keyboard interfacing (Matrix keyboard scanning, debouncing).
   - Mouse interfacing and serial communication.
   - Interfacing standards: USB, Bluetooth communication principle, RS-232.
   - Volatile vs. Non-volatile memory (SRAM, DRAM, ROM, Flash).
