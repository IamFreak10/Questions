## 📑 Core Syllabus Areas for Mid-Term
1. **Intelligent Agents & Problem Formulation**:
   - Agent architectures: Simple reflex agents, Model-based reflex agents, Goal-based agents, Utility-based agents, Learning agents.
   - PEAS description (Performance Measure, Environment, Actuators, Sensors).
   - Environment types: Fully vs. Partially observable, Deterministic vs. Stochastic, Static vs. Dynamic, Discrete vs. Continuous.
2. **Uninformed (Blind) Search Strategies**:
   - Breadth-First Search (BFS), Depth-First Search (DFS), Depth-Limited Search (DLS), Iterative Deepening DFS (IDDFS), Uniform Cost Search (UCS).
   - Evaluation metrics: Completeness, Time Complexity, Space Complexity, Optimality.
3. **Informed (Heuristic) Search Strategies**:
   - Greedy Best-First Search ($f(n) = h(n)$).
   - $A^*$ Search ($f(n) = g(n) + h(n)$).
   - Heuristic properties: Admissibility ($h(n) \le h^*(n)$), Consistency / Monotonicity ($h(n) \le c(n, a, n') + h(n')$).
4. **Adversarial Search & CSP**:
   - Minimax algorithm, Alpha-Beta pruning.
   - Constraint Satisfaction Problems (CSP): Backtracking search, AC-3 constraint propagation.
