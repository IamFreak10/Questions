### 1. 

**1)** Make an NFA: Strings where the first symbol is present somewhere later on at least once.

**2)** i) Analyze about the "Bad Case for the Subset Construction" during DFA to NFA conversion. ii) Describe the "pigeonhole principle" regarding the subset construction.

**3)** Build in ε-NFA for the following language: L = {w | w is empty, or if non-empty will end in 01}

**4)** i) Prove that if we add a finite set of strings to a regular language, the result is a regular language. ii) A language L is accepted by some e-NFA if and only if L is accepted by some DFA.

**5)** Convert the following RE to ε-NFA: (0+1)*01(0+1)*

**6)** i) Prove the theorem "a mod b = b mod a, if and only if a = b. ii) By method of induction, proof the theorem "if x ≥ 4 then 2* ≥ x².

**7)** Describe the importance of Automata Theory.
